## cronmiss

Know when a cron job didn't run.

Give each scheduled job a ping URL and its schedule. When an expected ping doesn't arrive within the grace window, you get an email that says which run was missed and when it was due.

- Site and guides: https://cronmiss.com
- Clients: `npm i cronmiss` · `pip install cronmiss`
- Our own monitoring, in public: [cronmiss/canary](https://github.com/cronmiss/canary)

Pre-signups are open at https://cronmiss.com/join/. Questions: support@cronmiss.com
